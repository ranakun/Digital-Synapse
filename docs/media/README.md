# Public presentation images

These images use **fictional example data only**. No personal vault, real exports, private conversations or host screenshots appear in them.

- `knowledge-map.png`: the unmodified v2 Alpha 1 viewer at 1440 × 960, showing the computed overview of a disposable workspace containing 72 fictional source notes. Its topics cover photography, gardening, focused work, learning to code, community activities and bread baking. Only the displayed subset is pictured; labels, layout, counts and similarity connections are produced by the real application.
- `source-inspector.png`: the same viewer after opening **Balcony & Garden** and selecting **Compost experiment**. The excerpt and computed connection come from the retained synthetic material.
- `social-preview.png`: a 1280 × 640 share card composed from `social-preview.html` and the actual overview screenshot. The frame and headings are presentation artwork, not an additional application screen.

Captured 12 September 2026 from the public release (`v2.0.0-alpha.1`). The screenshots show existing UI; no application code, CSS, labels or graph output were edited for these images. Example questions elsewhere in the README are illustrative and are not fabricated agent answers.

The social card uses the application's bundled IBM Plex Sans fonts and their existing license. To re-render it, open `social-preview.html` with a 1280 × 640 viewport and capture the page after fonts and images load. Keep image captions and alternative text when reusing these assets. New screenshots must use an isolated synthetic workspace, never a user's active vault.
