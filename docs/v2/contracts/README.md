# Retained knowledge contracts

The JSON files here are synthetic examples and hash vectors. They are not user knowledge or approval. The schema matches the packaged runtime schema in `src/synapse/schemas/synapse-v2.schema.json`.

Discover actual runtime capabilities with `synapse v2 describe` or `synapse_v2_describe`. The specialist role documents exact read argument fields, evidence closure and review/authority boundaries. Code and synthetic contract tests define hashing/version semantics.

Public v2 preserves nonempty legacy entity identifiers and references while new knowledge/source/operation identifiers retain their typed constraints. Migration never invents passage anchors or reattests historical labels.
